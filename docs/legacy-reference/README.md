# Historical Report Source

This directory preserves the original 2011 report sources before the documentation is modernized.

- `Filter.tex` is the original Scientific Word/LaTeX report source.
- `figures/` contains the EPS assets referenced by `Filter.tex`.
- `FilterCode.htm` is the original exported code snapshot.

These files are reference material only. `Filter.tex` requires the legacy `tcilatex` package, which is not included, and does not describe the current cascaded runtime implementation. New documentation should be authored independently under `docs` and cite this archive only when historical context is useful.
